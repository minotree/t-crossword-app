# 소설·에세이 한글 해석 다듬기

- 날짜: 2026-10-21 (Asia/Seoul)
- 도구: Codex. 구체적인 모델 식별자는 제공되지 않음.
- 요청: 그림책의 소설·에세이 해석이 딱딱하다는 사용자 의견.
- 자료: 저장소의 중급·고급 `books.json` 영어 원문과 기존 한글 해석만 사용했다. 외부 번역문은 참조하지 않았다.
- 편집 지시: 영어 원문의 의미와 작품별 분위기를 유지하면서 직역투·추상적인 명사 표현·부자연스러운 대사를 자연스러운 한국어로 다듬는다.

## 검토와 반영

중급 소설·에세이 6편 33장, 고급 소설·에세이 5편 36장의 영어 원문과 해석을 대조했다. 그중 11편 55장의 해석을 수정했다. 정확한 수정 페이지는 `picture-book-approval.json`의 작품별 `translationReview.pages`에 기록했다.

- 에세이: “내 미래 전체를 재지는 못한다” 등의 직역을 풀고, 화자의 생각이 자연스럽게 이어지도록 다듬었다.
- 소설: 인물 관계·사건 순서·대사의 뜻을 유지하며 실제 대화에 가까운 표현을 사용했다. 환생 소설 6장은 원문의 공동 행동 주어에 맞춰 “우리는”으로 바로잡았다.
- 고급 SF: 기억 열람·연락 동의의 범위를 구별하고, 오빠·여동생 관계와 화해의 유보를 유지했다.
- 미스터리: 보관금이 미지급 보수라는 설정과 은행 확인 절차를 유지했다.
- 법정 드라마: 가상의 절차라는 설명과 위약금 청구·납품 지연 책임의 구별을 유지했다.

영어 원문·제목·이미지·페이지 순서는 변경하지 않았다. 시는 이번 편집 대상에서 제외했다. 변경된 해석을 영어 원문과 다시 대조한 뒤 해당 작품의 콘텐츠 해시와 번역 검토 기록을 갱신했다. 기존 이미지·권리 검토 기록은 유지하며 이번 편집이 새로운 이미지 시각 검수나 포괄적인 권리 재검증을 뜻하지는 않는다.

## 검증

- 중급·고급 `build-preview.py`: 어휘 검사, 이미지·제작 기록 대응 및 갤러리 생성 통과.
- `python scripts/prepare-picture-books.py`: 웹 파생 데이터 생성.
- `node scripts/prepare-toss-picture-books.mjs`: 승인 해시·이미지 대응 검사 및 토스 파생 데이터 생성.
- 실제 브라우저·토스 기기의 해석 표시와 가독성 확인은 미실행.
- `pnpm.cmd --config.verifyDepsBeforeRun=false --filter @t-crossword/web build`: 통과(TypeScript 검사 포함).
- `pnpm.cmd --config.verifyDepsBeforeRun=false --filter @t-crossword/toss build`: 통과(TypeScript·승인 해시 검사 포함).
- 두 빌드에서 500 kB 초과 청크 경고가 있었다.
- 원본 JSON을 HEAD와 비교해 해석 외 필드가 동일하고 수정 페이지가 55장임을 확인했다. `git diff --check` 통과.
