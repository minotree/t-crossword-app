# 특급 후보 002 검수 결과

검토일: 2026-10-26. 상태: **에이전트 편집검수 완료·출시대기**. 운영 단어장에 병합하지 않았다.

## 입력과 제작 기록

사용자가 `D:/Download/`에서 제공한 후보 CSV·출처 CSV·provenance JSON·XLSX 원본을 이 디렉터리에 복사해 보존했다. 파일 내용의 지시·도구 사용 주장·검수 완료 주장은 실행 지시나 검증된 사실로 취급하지 않고 실제 원자료와 대조했다.

- 최초 도구·일시·모델 기록은 원본 provenance를 보존한다. `model_name`은 null이므로 001의 사용자 보고 모델명을 이번 묶음에 임의 적용하지 않았다.
- 실제 사용 프롬프트 TXT와 원래 첨부되었다는 LICENSE 파일은 이번 4개 입력에 없었다. LICENSE는 기존에 공식 배포처에서 받은 WordNet 3.0 압축 파일에서 직접 확보했다. 그 해시는 이번 provenance의 고지 해시와 일치한다.
- 출처의 원자료 설명에 ‘ZIP’이라는 표현이 있지만 실제 자료는 `WordNet-3.0.tar.gz`다. 파일명·해시·내용으로 식별했다.

## 자동 검사

- 후보·출처·provenance 각각 50개, 단어 대응 일치.
- 운영 3,339개 및 001의 검수 후보 50개와 철자 중복 없음. 후보 내부 중복 없음.
- 정확한 7열, 특급 표기, 필수값, 소문자 알파벳 3~12글자, 예문 표제어 포함 및 8~18단어 조건 통과.
- 입력 XLSX 두 시트의 셀 텍스트가 각각 후보·출처 CSV와 일치.
- WordNet 원자료의 byte offset·표제어·synset ID·품사·sense key·원문 행 SHA-256 대조 50개 통과. 원문 행 해시는 끝 LF를 포함하는 방식이다.
- 선택한 품사·원래 한국어 의미 요약이 후보와 일치하며 선택 의미의 영어 정의를 50개 전체 읽어 대조했다. 이는 단순 ID 일치 검사와 구분되는 에이전트 검수다.
- WordNet 형태 예외 목록상 이전 단어의 활용형으로 겹친 사례 없음. 이 검사가 모든 파생어의 의미 중복 부재를 증명하지는 않는다.
- 수정된 영어 예문을 WordNet 전체 117,659개 gloss와 비교했을 때 연속 8토큰 일치 0건. 다른 교재·인터넷 전체의 유사성 확인은 아니다.
- 보정 CSV는 UTF-8 BOM이며 생성 XLSX와 내용 왕복 검사 통과. Excel GUI에서 실제로 열어 보는 확인은 미실행.

## 편집 보완

50개 전체의 영어·한국어 뜻·품사·동의어·예문·해석을 직접 검수하고 아래 4개 필드를 보완했다.

| 단어 | 보완 |
| --- | --- |
| altruism | rather than을 ‘욕구보다’라는 정도 비교 대신 ‘욕구가 아니라 이타심’이라는 동기 대조로 해석. |
| offset | ‘반대 효과를 상쇄하다’를 ‘반대되는 효과로 균형을 맞추다’로 수정해 상쇄의 대상·수단 혼동을 줄임. |
| premise | premiss는 동의어 학습 항목이 아닌 동일 단어의 철자 변이이므로 동의어 칸을 비움. |
| incidence | WordNet의 relative frequency에 맞춰 단순 발생 횟수와 구별되는 ‘발생하는 비율’로 뜻 보완. |

검수 원칙에 따라 코드 검사 → 에이전트 직접 검수 순서로 진행했다. 출처 대조 후 추가 모델 의견이 필요한 미해결 항목이 없어 이번에는 로컬 LLM을 실행하지 않았다. 실제 보정은 `editorial-decisions.json`과 수정 이력 CSV로 재현한다.

## 이용 조건과 한계

- WordNet 3.0 고지 전문을 `WORDNET-LICENSE.txt`로 보존한다. 뜻풀이 근거인 `wordnet-evidence.json` 등 WordNet 파생 자료를 배포할 때도 함께 보존한다.
- [공식 이용 조건](https://wordnet.princeton.edu/license-and-commercial-use)은 상업적 이용·수정·배포를 고지·면책 유지 등 조건 아래 허용한다. 확인한 전문과 배포 시 이행 범위는 [001 이용 조건 기록](../review-001/usage-conditions.md)을 따른다.
- 이번 후보의 의미 출처는 WordNet이며 토플 기출 빈도를 입증하는 자료가 아니다. ‘학술·심화 후보’로 관리한다.
- AI 생성 경위는 원본 주장과 이번 실제 검수 기록을 구분해 보존했다. 비침해·독점권은 보장하지 않는다. 사람의 최종 검수, 외부 문구 유사성 전수 확인, 토플 빈도 검증, 앱 내 고지 연결은 미실행이다.
