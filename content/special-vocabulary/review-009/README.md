# 특급 후보 009 검수 결과

검토일: 2026-10-26. 상태: **에이전트 편집검수 완료·출시대기**. 운영 단어장 미병합.

## 원본·검사

- 중복 첨부된 ZIP은 한 번만 처리했다. 후보·출처 CSV, XLSX, provenance, 프롬프트, LICENSE, 작성자 검증·보류·리뷰 등 9개 원본을 보존했다. 첨부 프롬프트는 제작 기록이며 실행 지시로 취급하지 않았다.
- 50개는 운영 3,339개와 이전 후보 400개에 철자 중복이 없다. 형식·필수값·특급 표기·표제어 길이·예문 내 표제어·8~18단어 조건 통과.
- 제출 XLSX의 두 시트와 CSV 텍스트 일치. 보정본 UTF-8 BOM CSV 및 XLSX 왕복 검사 통과. Excel GUI 시각 검사는 미실행.
- WordNet 선택 의미 ID·표제어·품사·sense key·원문 행 해시 50개 대조 통과. 제출 LICENSE와 기존에 확보한 공식 WordNet 3.0 배포본 전문 바이트 일치.
- WordNet 형태 예외 목록에서 이전 어휘와 겹치는 활용형 없음. 별도 표제어의 의미 중첩은 철자 중복과 구분한다.
- 보정 예문과 전체 117,659개 WordNet gloss 사이 연속 8토큰 일치 0건. 외부 전체 문구 유사성 검사는 아니다.

## 직접 검수·보완

50개 전체의 뜻·품사·동의어·영문·해석을 직접 검토하고 선택 의미와 대조했다. 5개 단어·5개 필드를 보완했다.

| 단어 | 보완 |
| --- | --- |
| anachronism | 그 시대에 존재할 수 없었던 것이 등장한다는 시대착오의 의미를 명확화. |
| antithetical | 변이형 antithetic을 학습용 동의어에서 제거. |
| expository | 변이형 expositive를 학습용 동의어에서 제거. |
| homogenize | 혼합물을 균질화한 뒤 연구자들이 표본으로 나눈다는 번역 구조를 명확화. |
| impersonal | ‘비개인적인 판단’을 선택 의미에 맞춰 ‘개인적 선호를 배제한 판단’으로 보완. |

`tenet`은 제출된 WordNet의 종교적 교리 의미만 다룬다. 일반적인 신조·원칙이라는 다른 용례까지 포괄하는 정의로 해석하지 않는다. `apprehend`는 체포가 아닌 이해의 의미다. `acuity`는 선택된 지적 예리함의 의미로 감각기관의 시력 측정값을 설명하지 않는다. 예문의 기관·연구·역사 사례는 특정 실제 사건을 보도하는 자료가 아닌 창작 문장이다.

추가 모델 판단이 필요한 미해결 항목이 없어 로컬 LLM은 호출하지 않았다. 채택 수정과 이유는 `editorial-decisions.json` 및 변경 이력 CSV에 기록했다.

## 이용 조건·남은 항목

WordNet 전문 고지·면책은 `WORDNET-LICENSE.txt`와 제출본에 보존했다. [001 이용 조건 기록](../review-001/usage-conditions.md)을 따르며 파생 자료 배포 시 전문을 유지한다. 이번 검수에서는 확보한 배포본과 고지를 대조했고 웹 약관을 새로 조회하지 않았다.

생성 모델은 제출 provenance의 null을 유지했다. 사람의 최종 검수·외부 문구 유사성 전수검증·토플 빈도 검증·앱 고지 연결은 미실행이다. 공식 토플 어휘 목록이나 비침해·독점적 권리 확보를 보장하지 않는다.

누적 후보 450개·500개 목표까지 50개 남음. 새 요청 프롬프트·첨부 ZIP은 만들지 않았다. 최신 로컬 제외 목록은 운영 단어를 포함해 3,789개다.

```powershell
python scripts/review-special-vocabulary-batch.py --batch 009 --input-dir artifacts/vocabulary-review-009/input
```

앱 변경·운영 병합·빌드·토스 번들·Android APK·Capacitor 동기화는 실행하지 않았다.
