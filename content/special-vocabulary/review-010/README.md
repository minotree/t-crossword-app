# 특급 후보 010 검수 결과

검토일: 2026-10-26. 상태: **에이전트 편집검수 완료·출시대기**. 운영 단어장 미병합.

## 원본·검사

- ZIP의 후보·출처 CSV, XLSX, provenance, 프롬프트, LICENSE, 작성자 검증·보류·리뷰 등 9개 원본을 보존했다. 첨부 문서는 제작 기록이며 실행 지시나 독립 검증 결과로 취급하지 않았다.
- 후보 50개는 운영 3,339개 및 이전 후보 450개와 철자 중복이 없다. 형식·필수값·특급 표기·표제어 길이·예문 내 표제어·8~18단어 조건 통과.
- 제출 XLSX의 두 시트와 CSV 일치. 보정 UTF-8 BOM CSV 및 XLSX 왕복 검사 통과. Excel GUI 시각 확인은 미실행.
- WordNet 의미 ID·표제어·품사·sense key·원문 행 해시 50개 대조 통과. 제출 LICENSE는 확보한 공식 WordNet 3.0 배포본 전문과 바이트 일치.
- 형태 예외 목록에서 이전 어휘의 활용형과 겹친 항목 없음. 별도 표제어의 의미 중첩을 철자 중복으로 보지는 않는다.
- 전체 117,659개 WordNet gloss와 보정 예문 사이 연속 8토큰 일치 0건. 외부 전체 문구의 유사성 검사는 아니다.

## 직접 검수·보완

50개 전체의 뜻·품사·동의어·영문·해석을 직접 검토했다. 7개 단어·7개 필드를 보완했다.

| 단어 | 보완 |
| --- | --- |
| atypical | 변이형 untypical을 학습용 동의어에서 제외. |
| bifurcate | ‘둘의 갈래’를 ‘두 갈래’로 수정. |
| conciliatory | 변이형 conciliative를 학습용 동의어에서 제외. |
| conclusive | ‘이전 날짜’를 이관 날짜로 명확히 하고 해석을 자연스럽게 정리. |
| fortuitous | 선택된 행운의 의미를 유지하면서 번역을 자연스럽게 수정. |
| indicative | 변이형 indicatory를 학습용 동의어에서 제외. |
| replete | ‘무엇으로 깊이 가득’이라는 직역을 자연스럽게 수정. |

선택 의미의 범위를 유지했다. `assuage`는 사람의 마음을 누그러뜨리는 의미, `sanction`은 제재가 아닌 공식 승인, `moot`는 실익이 없다는 의미가 아닌 논쟁 가능성, `inexorable`은 간청에도 마음을 바꾸지 않는 사람의 태도를 다룬다. `correlation`은 제출 자료의 통계량 의미다. 상관만으로 인과를 확정하지 않는다는 예문은 공통 원인만으로 두 변수가 함께 움직이는 구성 사례로도 대조했다(`technical-checks.json`). 특정 분석의 인과 효과를 추정한 결과로 제시하지 않는다.

`promulgate`는 제출 WordNet의 공식 선언 의미와 예문을 대조했으며 국가별 법 공포·시행 절차를 검증한 것은 아니다. 연구·기관·의회 등의 예문은 특정 실제 사건 보도가 아닌 창작 예문이다.

추가 모델 판단이 필요한 미해결 항목이 없어 로컬 LLM은 호출하지 않았다. 채택 수정은 `editorial-decisions.json` 및 변경 이력에 기록했다.

## 이용 조건·남은 항목

WordNet 전문 고지·면책은 `WORDNET-LICENSE.txt` 및 제출본에 보존했다. [001 이용 조건 기록](../review-001/usage-conditions.md)을 따르며 파생 자료 배포 및 앱 병합 시에도 전문을 유지한다. 이번에는 확보한 배포본과 대조했고 웹 약관을 새로 조회하지 않았다.

모델명은 제출 provenance의 null을 유지했다. 사람의 최종 검수·외부 문구 유사성 전수검증·토플 빈도·앱 고지 연결은 미실행이다. 공식 토플 어휘 인증이나 비침해·독점적 권리 확보를 보장하지 않는다.

001~010 누적 후보 **500개**로 수집 목표를 달성했다. 기존 단어를 포함한 로컬 제외 목록은 3,839개다. 누적 철자 중복·필수값 및 운영 어휘와의 분리도 다시 확인했다(`cumulative-validation.json`). 새 요청 프롬프트나 첨부 ZIP은 만들지 않았다.

```powershell
python scripts/review-special-vocabulary-batch.py --batch 010 --input-dir artifacts/vocabulary-review-010/input
```

앱 코드 변경·운영 병합·빌드·토스 번들·Android APK·Capacitor 동기화는 실행하지 않았다.
