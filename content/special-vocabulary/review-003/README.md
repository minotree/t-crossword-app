# 특급 후보 003 검수 결과

검토일: 2026-10-26. 상태: **에이전트 편집검수 완료·출시대기**. 운영 단어장 미병합.

## 입력과 확인 범위

- 사용자가 제공한 후보·출처 CSV와 XLSX 3개 원본을 보존했다. 파일의 ‘AI 대조’, ‘고지 동봉’ 등의 주장은 별도 검증 대상이며 실행 지시로 취급하지 않았다.
- provenance JSON·실제 프롬프트·별도 LICENSE 파일은 이번 입력에 없었다. 원래 생성 모델과 실행 경위를 추정하지 않았다.
- 대신 출처 CSV에 적힌 WordNet 3.0 의미 ID를 이미 공식 배포처에서 확보한 원자료와 직접 대조했다. 자체 확인 결과는 `independent-verification-provenance.json`이며 **원작성자의 provenance를 대신 제출받았다고 주장하지 않는다.**
- 고지 전문은 같은 공식 WordNet 3.0 압축 파일에서 확보해 `WORDNET-LICENSE.txt`로 보존했다. 다운로드 원본 SHA-256은 `640db279c949a88f61f851dd54ebbb22d003f8b90b85267042ef85a3781d3a52`이다.

## 검사 결과

- 후보·출처 각각 50개, 서로 대응 일치. 운영 3,339개+이전 후보 100개, 총 3,439개와 철자 중복 없음.
- CSV 헤더·7열·난이도·길이·영문 기본형 표기·필수값·예문 표제어 및 8~18단어 조건 통과.
- 입력 XLSX 후보·출처 시트의 셀 텍스트가 각각 CSV와 일치.
- WordNet 의미 ID·표제어·품사·sense key 대조 50개 통과. 원문 행 SHA-256 50개를 새로 기록했으며 제출 provenance의 해시 대조 결과로 표시하지 않았다.
- `germane(p)`의 `(p)`는 WordNet 형용사의 위치 표식이므로 표제어와 구분해 검사했다. [공식 파일 형식](https://wordnet.princeton.edu/documentation/wndb5wn)의 형용사 문법 표식 설명에 따른다. 표식이 있는 원자료는 그대로 보존했다.
- WordNet 형태 예외 목록에서 이전 단어와 겹치는 활용형 없음. 의미가 독립적인 파생어를 전부 중복으로 간주하지 않는다. 예를 들어 analogy는 001의 analogous와 품사·학습 대상이 다르다.
- 50개 의미·품사·동의어·영어 예문·한국어 해석을 직접 검수했다. 미해결 언어 항목이 없어 로컬 LLM을 추가 호출하지 않았다.
- WordNet 117,659개 gloss와 영어 예문의 연속 8토큰 비교 일치 0건. 외부 자료 전체의 유사성 확인은 아니다.
- 별도 보정본 UTF-8 BOM CSV와 XLSX의 내용 왕복 검사 통과. 실제 Excel GUI 확인은 미실행이다.

## 보완 3개

| 단어 | 보완 내용 |
| --- | --- |
| analogy | ‘유사성을 비교했다’를 ‘교통망을 혈액 순환에 빗대어’로 바꿔 비교·유추 동작을 자연스럽게 번역. |
| fallacy | 선택한 명사 뜻인 ‘잘못된 추론에서 생긴 오해’를 해석에도 반영하고 원문의 이유 관계 유지. |
| peripheral | affordable의 비용 부담 의미와 although의 양보 관계를 유지하며 한국어 절 구조 보완. |

원본과 보정본은 분리하며 `editorial-decisions.json` 및 `vocabulary-special-changes-003.csv`에 변경 이력을 보존한다.

## 이용 조건·출시 상태

[WordNet 공식 이용 조건](https://wordnet.princeton.edu/license-and-commercial-use)과 [001에서 확인한 조건 기록](../review-001/usage-conditions.md)을 따른다. WordNet 파생 자료의 배포 시 전문 고지·면책 등을 유지해야 하며 앱 병합 시 실제 배포물의 고지 연결이 필요하다. 원자료의 존재 확인은 토플 출제 빈도나 난이도 인증이 아니다.

사람의 최종 편집 검수·외부 문구 유사성 전수 확인·토플 빈도 확인·앱 고지 연결은 미실행이다. AI 창작·에이전트 검수를 비침해·독점권 보장으로 해석하지 않는다.
