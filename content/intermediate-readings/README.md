## 어휘 및 검증

내용 어휘는 프로젝트의 초급·중급 목록을 누적 사용한다. 관사·대명사·전치사·조동사 등 기본 문법어 중 목록에 없는 항목은 `validate.py`에 명시한다. 동사의 과거형·진행형, 복수형, 비교급은 기존 어휘의 활용형으로 기록한다. `driver → drive`, `farmer → farm`, `poster → post`, `phone → telephone`의 네 가지 일반적인 단어족·축약형은 별도 명시해 보고서의 `derivations`에 기록하며, 기본 어휘 수에 별도 단어로 더하지 않는다. 그 외 고급 내용 어휘를 임의로 허용하지 않는다. 한글 해석은 어색한 직역보다 문맥과 원문의 의미를 살려 작성했다.

저장소 루트에서 실행한다(Python/Pillow 필요).

```powershell
python content/intermediate-readings/validate.py
python content/intermediate-readings/build-preview.py
python scripts/prepare-picture-books.py
```

마지막 명령은 웹용 WebP와 목록을 생성한다. 웹에서 중급을 선택하고 작품을 열면 이전·다음으로 페이지를 이동하며, 페이지마다 해석을 펼칠 수 있다. 초급 45편은 기존 콘텐츠를 유지한다.

영어 원문을 수정하면 해석·이미지 속 본문·생성 기록·검수 갤러리도 함께 맞춘다. 이미지 제작 전에 관사·수일치·시제와 번역 대응을 확인하고, 연속 작품은 인물별 나이·외형·역할을 구분한다. 보정본은 원본과 별도 버전 파일로 보존한다. 웹용 JSON·WebP만 직접 고치지 않는다. 스크린리더용 영어 텍스트와 AI 활용 표시를 유지하며 오프라인 범위는 [웹/PWA 문서](../../docs/vercel-pwa.md)를 따른다.

## 제작·권리 기록

2026-10-19 어휘 검사에서 `copied → cop`로 잘못 연결되던 규칙을 고쳤다. `-ied`에서만 `y`를 복원하고, 중복 자음이 있는 형태에만 자음 하나를 제거한다. 현재 보고서는 `copied → copy`로 기록한다. `python content/test-vocabulary-audit.py`로 회귀 검사를 실행한다.

- 제작일: 2026-10-16 (Asia/Seoul).
- 영어 원문·해석: 이 작업에서 직접 창작·번역. 외부 시·에세이·소설·번역문을 참조하거나 개작하지 않았다. 창작 에세이는 실제 인물의 경험을 인용한 글이 아니다.
- 삽화: 내장 ImageGen. 모델의 구체적인 식별자는 도구에서 제공하지 않는다. 외부 참조 이미지 없이 독자적인 인물·장면으로 제작한다. 특정 작가·브랜드·기존 캐릭터를 프롬프트에 사용하지 않는다.
- 기존 어휘 데이터의 출처·이용 권한은 이번 작업에서 재검증하지 않았다.
- 검수 전 콘텐츠 초안이며, AI 생성만으로 비침해나 독점적 권리를 보장하지 않는다. 배포 전 기존 작품 유사성, 도구 이용 조건, 영어 표현·해석의 교육 적합성 검토가 필요하다.
- 제작한 36장의 제목·영어 본문을 원본 데이터와 시각적으로 대조했다. 이는 최종 편집·권리 검토나 실제 기기에서의 가독성 확인을 대신하지 않는다.
- SF의 시간 이동 장치는 허구다. 실험실 장면은 미성년자가 위험 장치를 직접 조작하지 않고 어른에게 알리는 흐름으로 작성했다.
- 무협은 가상의 산중 수련장과 마을을 배경으로 하며, 비선정적이고 잔혹하지 않은 수련·협력 이야기다. 환생 소설은 전생의 기억을 가진 가상 왕자의 이야기이며 기존 작품의 인물·설정·사건을 개작하지 않았다.
