# Source Serif 4

Unmodified Adobe Source Serif fonts, used offline for picture-book raster typography.
Official source: https://github.com/adobe-fonts/source-serif

Pinned revision, download URLs, byte sizes and SHA-256 hashes are in provenance.json.
