# 초급 영어 동시·삽화 45편

2026-10-19 최신 상태: 45편·45장의 전체 카드 대조와 제작 기록·도구 이용 조건 검토 후 원본을 `approved`로 기록하고 토스에도 연결했다. 초급 32편을 추가 교정해 누적 15장의 초급 보정본을 사용한다. 아래 최초 제작 당시 초안 설명과 구별하며 [전체 검토 범위·한계](../picture-book-final-review-2026-10-19.md)를 따른다. 실제 토스 기기 검증은 별도다.

공통 제작·권리·검수 규칙은 [AGENTS.md](../../AGENTS.md) 14~15절을 따른다. 이 문서의 편수·행 수는 현재 제작분의 기준이며 후속 작품의 고정 제한은 아니다.

- `poems.json`: 제목, 영어 동시, 한글 해석(`translation`), 사용 단어, 장면 설명, 이미지 경로. 기존 20편은 4행, 추가 25편은 6행이다. 해석은 영어와 같은 행 수로 작성했다.
- `images/`: 작품별 삽화와 영어 원문을 함께 담은 이미지.
- `index.html`: 로컬에서 열어 전체 작품을 볼 수 있는 갤러리. 각 작품을 펼치면 원문과 사용 단어를 확인할 수 있다.
- `coverage-report.json`: 본문에 사용된 단어 목록, 단어별 등장 작품, 미사용 단어 목록과 목표 달성 여부.
- `overview.jpg`: 전체 작품 이미지 모음. `review-expansion-*.jpg`는 추가 작품의 글자 대조용 모음이다.
- 난이도 기준: 현재 `packages/core/src/assets/vocab.json`의 초급 775종을 사용한다. 목록 밖 기본 문법어 `a, me, my, their, to, your, on`과 복수형 `socks → sock`, `shoes → shoe`, `teeth → tooth`, `hands → hand`, `toys → toy`를 검사 코드에 명시하고 보고서에 따로 기록한다. 제목도 동일하게 검사한다.
- 목표: 제목·단어 목록·장면 설명을 제외한 **동시 본문에서 서로 다른 초급 기본 어휘 500종 이상** 사용. 2026-10-19 교정 후 **536종**으로 목표를 달성한다. 기존 20편 본문은 161종이고, 추가분에서 375종을 새로 사용한다. 문법어는 제외하며 복수형은 기본형으로 합쳐 중복 집계하지 않는다. 이전 537종은 교정 전 본문 기준이고, 167종은 최초 20편 제목 포함 수치다.
- 집계: 대소문자를 합치고 구두점을 제거한다. 하이픈으로 연결된 단어는 한 단어로 취급한다. 동일 단어의 반복은 추가 집계하지 않는다.

## 2026-10-19 편집 교정

14편의 부자연스러운 표현·단복수·번역 대응을 교정하고 카드 `-v2.png`를 제작했다. 21·22편은 화자를 명확히 한 `-v3.png`를 사용하며 중간 보정본도 보존한다. 문법어 `I`도 별도 허용·기록한다. 이전 PNG와 제작 기록은 보존하며, 최초 통합 기록은 `generation-record-20261016.json`에 보관한다. 최신 `generation-record.json`은 현재 사용하는 카드에 대응한다. 상세 변경·검증은 [검토 보고서](../picture-book-review-2026-10-19.md)를 따른다. 기본 어휘 데이터의 난이도는 변경하지 않는다. 최종 권리·전체 이미지 검토 전 초안 상태를 유지한다.

## 검증 및 갤러리 재생성

저장소 루트에서 실행한다. Python과 Pillow가 필요하며, 새 라이브러리는 추가하지 않았다.

```powershell
python content/beginner-poems/build-gallery.py
```

45편의 ID, 행 수, 실제 원문과 단어 목록의 일치, 초급 범위, 500종 목표, 생성 기록과 이미지 파일을 검사한 뒤 갤러리·보고서·이미지 모음을 다시 만든다. 브라우저에서의 실제 레이아웃 검증이나 저작권 검토를 대신하지 않는다.

## 제작 및 권리 검토 기록

- 제작일: 2026-10-16 (Asia/Seoul).
- 영어 원문: 이 작업에서 새로 작성. 외부 시·가사·교재를 참조하거나 개작하지 않음.
- 한글 해석: 각 영어 원문을 바탕으로 이 작업에서 직접 작성. 외부 번역문을 사용하지 않음.
- 삽화 도구: 내장 ImageGen. 모델의 구체적인 식별자는 도구 응답에 제공되지 않음.
- 참조 이미지: 없음. 기존 캐릭터·브랜드·작가 이름을 프롬프트에 사용하지 않음.
- 원문 데이터 출처: 프로젝트의 초급 단어 목록. 기존 단어 데이터 자체의 출처·이용 권한은 이번 작업에서 검증하지 않음.
- `generation-record.json`과 `generation-records/`에 제작분별 실제 이미지 요청 프롬프트와 생성 결과 위치를 기록한다.
- 권리 상태: 검수 전 초안. 생성 도구의 최신 상업적 이용 약관, 기존 작품과의 유사성, 기존 어휘 데이터의 이용 권한은 배포 전 확인해야 한다. 독점적 권리나 비침해를 보장하지 않는다.
- 편집 상태: 생성 이미지의 글자 누락·오타와 영어 표현의 자연스러움은 배포 전 최종 검수가 필요하다. 수정 기준 원문은 `poems.json`이다.
- 이번 확장 검증: 추가 25편의 제목과 6행 원문을 생성 이미지와 시각적으로 대조했다. 영어 표현의 자연스러움과 교육 적합성에 대한 최종 편집 검토는 별도로 남아 있다.
- 웹 하단 `그림책`의 초급 탭에 연결되어 있다. 페이지별 `해석 보기`와 스크린리더용 영어 텍스트를 제공하며 AI 활용 콘텐츠임을 표시한다. 기술 연결과 최종 편집·권리 검토 완료는 별개다.

## 원본 변경과 웹 반영

`poems.json`을 기준으로 영어·해석·이미지·생성 기록을 함께 맞춘다. 이미지 제작 전에 문법과 해석을 검토하고, 보정본은 버전 파일로 보존한다. 갤러리 검사 후 저장소 루트에서 `python scripts/prepare-picture-books.py`를 실행해 웹 JSON과 WebP를 갱신한다. 파생 파일만 직접 수정하지 않는다. 이미지의 오프라인 범위와 기기 검증은 [웹/PWA 문서](../../docs/vercel-pwa.md)를 따른다.
