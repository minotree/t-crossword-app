# 영어 퍼즐 게임 등급분류 준비

2026-10-21: 비게임 → 교육 신규 등록 준비로 방향을 변경했다. 이 문서는 기존 게임 등록 당시 이력으로 보존한다. 현재 작업은 [전환 문서](toss-nongame-transition.md)를 따른다. 기존 신청 취소나 법적 분류 판단은 완료하지 않았다.

작성·공식 자료 확인: 2026-10-20. **신청 전 초안**이며 등급 심사 결과·법률 의견·제출 완료 문서가 아니다. 실제 신청 화면의 최신 양식에 맞춰 옮긴다. 사업자·신분증·서명·계좌 원본은 저장소에 넣지 않는다.

## 현재 상태와 진행 순서

- 2026-10-20 후속 사용자 보고: 게임제작업 등록을 신청했고 제작품목은 `영어 퍼즐 게임`으로 입력했다. 접수번호·처리 결과·등록증 발급은 미확인이다. 향후 다른 게임 제작 범위까지 포함되는지와 보완 필요 여부는 담당자에게 확인하며, 취소·재신청이 필요하다고 단정하지 않는다. 아래 준비 순서는 신청 전 기준의 참고 자료다.

- 기존 개인사업자 보유. 사용자가 토스 콘솔 사업자 등록을 요청했고 제공한 화면은 검토 중이다. 승인·정산 등록은 미확인이다.
- 동일 게임의 타 스토어 출시/등급 이력 없음. 게임물제작업·게임물배급업 등록증 없음.
- 준비 기준은 **GRAC 직접 신청**이다. 타 스토어 설문 경로는 설문만이 아니라 동일 게임의 실제 출시 URL과 등급 증빙이 필요하므로 현재 확보한 경로로 취급하지 않는다.
- 우선 관할 시·군·구에 직접 제작하는 온라인 모바일 게임의 **게임제작업 등록 대상·예외·사업장 요건·서류**를 확인한다. 현재 사업자등록증에 업종이 있다는 사실만으로 별도 등록증 보유를 뜻하지 않는다. 불필요한 제작업·배급업 중복 신청을 전제하지 않는다.
- 이후 GRAC 업체 회원/신청 화면에서 신청 유형·간소화 대상 여부·구비서류·수수료를 확인한다. 토스 안내의 입력 기준은 모바일 게임·기타-앱인토스·인터넷 접속이다. 실제 시스템 항목과 다르면 담당자에게 확인한다.
- 설명서, 실행물 접근 방법, 영상·화면, 권리 자료를 준비하고 제출본을 고정한다. 발급된 등급 자료를 토스 콘솔에 등록하는 것은 별도 단계다.

근거: [토스 등급분류 안내](https://toss.im/apps-in-toss/blog/game_rating_classification), [토스 콘솔 게임 등급분류](https://developers-apps-in-toss.toss.im/guide/operation/console-workspace#5-3).

## 게임제작업 등록 준비

### 도봉구 확인 경로 (2026-10-20)

사용자가 사업장 소재지를 서울 도봉구로 확인했다. 도봉구청 공식 민원편람의 [게임업 변경신청 안내](https://www.dobong.go.kr/wdb_dev/MINWON/view.asp?idx=209&intPage=20) 검색 결과에서 문화체육과·02-2091-2257을 확인했다. 이는 **변경 민원에 기재된 연락처**이므로 신규 게임제작업 담당 연결 여부를 먼저 확인한다. 개별 직원명은 기록하지 않는다. 직접 페이지 열기는 도구에서 실패했고 공식 검색 본문을 확인한 범위다.

해당 페이지의 5,000원은 변경 민원 수수료이며 신규 등록 비용으로 사용하지 않는다. 신규 등록의 도봉구 전용 서류·비용·사업장 요건·예외는 미확인이다. 아래 공통 준비물과 문의 초안을 기준으로 담당자에게 확인한다.

전화 시 우선 질문: “게임제작업 신규 등록 담당자 연결 부탁드립니다. 기존 도봉구 개인사업자로 직접 제작한 앱인토스 모바일 퍼즐을 서비스하려고 하는데, 등록 대상 여부와 사업장 요건, 준비 서류 및 신규 수수료를 확인하고 싶습니다.”

[정부24 게임제작(배급)업 등록](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=13700000177)은 시·군·구 접수/처리, 인터넷·방문·우편 경로를 안내한다. 제작업에는 시설·장비 명세, 임차 시 임대차계약서 등이 제시돼 있다. 배급업 사업계획서는 별도 분류다. 해당 사업장에 적용되는 요건·서류·비용은 관할 부서에서 확인한다. 페이지의 총 3일·조례 수수료 안내를 실제 완료일이나 고정 비용으로 보장하지 않는다.

관할 부서 문의 초안(사용자가 직접 전달):

> 기존 개인사업자로 직접 만든 영어 십자낱말 모바일 게임을 앱인토스에서 처음 서비스하려고 합니다. 이용은 무료이고 배너 및 선택형 보상 광고를 포함하며, 게임 내 구매·환전·이용자 간 거래는 없습니다. 제 사업장의 게임제작업 등록 대상 여부와 예외, 재택/현재 사업장 요건, 기존 사업자 업종 정정 필요 여부, 신청서·시설/장비 명세·임대차 서류와 수수료를 확인하고 싶습니다. 직접 제작·서비스하는 경우 게임배급업도 별도로 필요한지 알려 주세요.

## 등급 관련 콘텐츠 확인 목록

아래는 실제 등급 기준 판정이 아닌 **추가 검토 후보**다. 목록 자체를 선정성/폭력성/약물/사행성 ‘있음’ 또는 ‘없음’의 자동 답안으로 쓰지 않는다.

- 어휘 파일의 표제어만 단순 문자열 확인한 결과: KILL, FIGHT, DEAD, DEATH, BLOOD, WINE, GUN, BEER, CRIME, DRUG, BET, PRISON, MURDER, SUICIDE, GAMBLE 등이 포함된다. 각 뜻·동의어·예문·해석과 실제 퀴즈 노출 맥락을 검토해야 한다.
- 그림책 영어 본문의 제한된 키워드 검색에서는 중급 에세이 `intermediate-essay-02` 3장, `intermediate-essay-03` 2장에 fight가 잡혔다. 비유·부정 표현 여부를 원문과 해석으로 확인한다. 이 검색은 이미지/한글/다른 활용형/우회 표현을 검사한 것이 아니다.
- 무협 `The Quiet Bridge`, 환생 `A Second Life, A Small Choice`, 미스터리 `The Last Customer`, 법정 `The Weight of a Signature`, SF `The Memory Deposit` 등은 소재와 실제 표현 수위·삽화를 함께 검토한다. 장르명만으로 등급을 판단하지 않는다.
- 119장 삽화의 기존 교정/권리 검토는 등급 심사를 대신하지 않는다. 노출·무기·상처·위협·공포 이미지 등은 등급 기준으로 다시 확인해야 한다.
- AI 창작·학습 목적을 설명하되 비침해·전체이용가·내용정보 없음으로 단정하지 않는다. [기존 검토 범위](../content/picture-book-final-review-2026-10-19.md), [광고 테스트 신뢰 경계](toss-ads.md)를 참고한다.

## 실행물·영상·화면 준비

- 실행 가능한 게임물 제출 방식은 GRAC 담당자에게 먼저 확인한다. `.ait`만으로 일반 기기에서 실행된다고 설명하지 않는다. 토스 로그인·콘솔 테스트 링크 접근 권한·테스트 기간·재현 방법을 확인하며 실제 계정 비밀번호는 공유하지 않는다.
- 문의 초안: “토스 앱 안에서 실행되는 WebView 게임입니다. .ait 번들과 콘솔 테스트 링크를 보유합니다. 심의 담당자가 실행할 수 있도록 제출할 공식 형식과 계정/기기·접근 권한 안내 방법을 확인하고 싶습니다.”
- 제출 영상은 실제 기기에서 홈 → 난이도/격자 → 입력/오답/힌트 → 한 판 완성 → 단어장 → 그림책 → 설정을 보여준다. 메뉴 진입만이 아니라 심사 판단에 영향을 주는 콘텐츠를 포함하고 실제 촬영 뒤 구간별 시간을 기록한다.
- 광고는 시청 전 선택, 중도 닫기 미지급, 완료 지급을 구분해 촬영한다. 현재는 테스트 ID·테스트 보상 API이므로 운영 수익 광고가 검증됐다고 표시하지 않는다. 제출 환경 허용 여부·운영 전환 범위는 별도 확인한다.
- 스크린샷 후보: 홈, 퀴즈 설정/플레이, 입력창, 완성 보상, 단어장/오답노트, 각 수준 그림책과 검토 후보 장면, 설정/광고 안내. 새로운 이미지나 녹화는 아직 만들지 않았다.
