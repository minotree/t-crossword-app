# 토스 비게임·교육 신규 등록 준비

## 최신 상태 (2026-10-21)

- 새 앱 `Load failed` 원인 중 CORS 차단을 확인하고 사용자 승인으로 새 테스트 Origin `https://english-words.private-apps.tossmini.com`을 서버에 허용했다. 기존 Origin은 유지했다. 원격 OPTIONS 양쪽 204·임의 Origin 403·새 Origin 무인증 balance 401 확인. 함수 재배포·DB 변경·mTLS 교체 없음. 앱 재시도와 실제 인증은 대기다. 아래 서버 미변경 기록은 번들 생성 당시 상태다.

- 사용자가 기존 앱을 유지하고 별도 신규 등록하는 것으로 변경했다. 아래 삭제 순서는 이전 계획이며 실행하지 않는다.
- 사용자 화면에서 새 앱 `영어 낱말`, appName `english-words`, 비게임과 카테고리 `생활 → 교육 → 교육` 선택을 확인했다. 로고·소개·기능 정보 입력을 진행했으며 검토 요청·공개 출시 완료는 아니다.
- 프로젝트 appName·HTML/화면 제목을 새 앱에 맞췄다. `apps/toss/english-words.ait` 생성 완료(30,450,388바이트). 로그인/mTLS·서버 Origin·광고와 실제 토스 동작은 새 앱에서 재검증해야 한다. 서버·DB 변경 및 업로드는 실행하지 않았다.

2026-10-21 사용자 결정: 출시 전 게임 등록을 삭제하고 비게임 → 교육으로 신규 등록한다. 삭제·신규 등록 완료와 최종 appName은 확인 대기다.

## 콘솔 등록 순서

1. 삭제 화면에서 삭제 범위와 기존 `t-crossword` 재사용 가능 여부를 확인한다. 재사용을 보장하지 않는다.
2. 앱 이름 `영어 낱말`, 유형 `비게임`, 카테고리 `교육`으로 신규 등록한다. 실제 콘솔 항목을 확인한다.
3. 소개 초안: “십자낱말 퀴즈로 영어 단어를 익히고, 단어장·오답노트와 수준별 그림책으로 복습하는 영어 학습 앱입니다.”
4. 등록된 앱 이름·appName을 프로젝트에 반영한다. 키·토큰·인증서 내용은 채팅이나 저장소에 기록하지 않는다.

## 등록 후 점검

- `apps/toss/apps-in-toss.config.ts`의 appName을 실제 등록 ID와 맞춘다. 유형 변경만으로 패키지 이름이나 공통 도메인 모델을 바꾸지 않는다.
- ID가 바뀌면 `.ait` 이름·업로드 명령·테스트 링크와 서버 `TOSS_ALLOWED_ORIGINS`를 검토한다. 서버 변경·배포는 별도 승인 후 실행한다.
- 새 앱의 로그인 설정·약관 URL·mTLS와 사용자 식별을 확인한다. 기존 사용자 키·잔액·로컬 기록의 자동 승계를 가정하지 않는다. 기존 DB 기록은 삭제하거나 임의 병합하지 않는다.
- 현재 광고는 테스트 ID다. 새 앱 운영 광고 등록·ID·보상 검증은 별도 확인한다. `docs/toss-ads.md`의 신뢰 경계를 유지한다.
- 업로드 권한을 확인한다. 필요한 토큰 등록은 사용자 로컬 `ait token add`로 처리하며 키 내용을 읽지 않는다.

## 비게임 검토 항목

[공식 비게임 출시 가이드](https://developers-apps-in-toss.toss.im/checklist/app-nongame.html)의 본문을 2026-10-21 확인했다. 다음은 우선 확인 항목이며 전체 검수 완료를 뜻하지 않는다.

- 토스 네비게이션 바와 최초 화면 뒤로가기 종료, 화면별 뒤로가기·홈 동작.
- 재접속 시 필요한 기록 유지. 진행 중인 퍼즐 복원 미구현과 학습 기록 보존을 구분해 검토한다.
- 진입 직후 로그인 바텀시트 자동 노출 여부, 서비스 소개·약관, 연결 해제 후 데이터 처리와 재동의.
- 공식 가이드는 배너를 스크롤 가능한 화면에만 노출하도록 명시한다. 현재 고정 하단 배너의 화면별 적합성을 재검토한다.
- 실제 광고·시청 완료 보상·닫기 복귀, 작은 화면·Safe Area·키보드·그림책 가독성을 새 앱에서 검증한다.

기존 게임 등급 준비 문서는 과거 이력으로 보존한다. 교육 카테고리만으로 법적 게임 해당 여부나 이미 신청한 게임제작업 등록의 취소 필요성을 확정하지 않는다.

현재 설정 ID 변경·서버/DB 변경·빌드·업로드·출시·새 앱 실기기 검증은 미실행이다. 기존 앱 테스트 결과를 새 앱의 검증 결과로 사용하지 않는다.
