## 기존 앱

2026-10-21 사용자 승인으로 신규 인증서·키를 `TOSS_ENGLISH_WORDS_MTLS_CERT_PEM` / `TOSS_ENGLISH_WORDS_MTLS_KEY_PEM`에 등록했다. 기존 `TOSS_MTLS_CERT_PEM` / `TOSS_MTLS_KEY_PEM`은 변경하지 않았다. 전달용 임시 파일은 등록 후 제거했으며 원본 파일은 보존했다. 두 앱의 사용자 ID는 서버에서 구분한다. 등록 성공·가짜 코드 401만으로 실제 인증 성공을 확정하지 않는다.

- 앱 이름 `영어 퍼즐`, appName `t-crossword`, 유형 게임. 사용자 결정으로 삭제하지 않고 유지한다.
- 기존 인증서의 관리 이름은 이 문서에서 확인하지 않았다. 신규 앱 인증서와 혼동하거나 임의로 교체하지 않는다.
